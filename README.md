# 🛍️ Sellya

**Sellya** is a modern Flutter-based marketplace app that allows users to **buy, sell, and manage items easily**.  
Built with Firebase backend and a sleek UI, Sellya provides a fast, secure, and user-friendly experience for mobile commerce.

---

## 🚀 Features

- 🔐 **User Authentication**
  - Secure login and signup (Firebase Auth)
  - Email and password authentication
  - Google sign-in support

- 💬 **Real-time Chat**
  - Chat directly with buyers/sellers
  - Instant message updates via Firebase

- 🛒 **Product Listings**
  - Post items with images, price, and details
  - Browse available products in real time
  - Filter and search for products easily

- 📸 **Custom UI**
  - Responsive design for all screen sizes
  - Material 3 design with animated transitions
  - App icon and splash screen customized

- ⚙️ **Firebase Integration**
  - Firebase Firestore (Database)
  - Firebase Authentication
  - Firebase Storage (for images)
  - Firebase Analytics & Crashlytics

---

## 🧰 Tech Stack

| Layer | Technology |
|-------|-------------|
| **Frontend** | Flutter (Dart) |
| **Backend** | Firebase |
| **Database** | Cloud Firestore |
| **Storage** | Firebase Storage |
| **Authentication** | Firebase Auth |
| **Crash Reporting** | Firebase Crashlytics |
| **UI Design** | Flutter Material 3 / Tailwind-inspired design |
